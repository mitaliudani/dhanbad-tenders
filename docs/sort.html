Seedha GeM se · aapke phone pe

GeM Sort Machine

GeM ki Dhanbad wali bid list yahan daaliye. Machine sirf goods bids rakhegi, closing date ke hisaab se lagayegi, aur Excel bana degi. Ye sab aapke phone ke andar hi hota hai; koi bot GeM ko nahi kholta.

  1. 1
    GeM pe Dhanbad ki list kholiye

    "Search by Consignee Location" → State: Jharkhand → City: Dhanbad → "View all Bids".

    GeM Advance Search kholiye
  2. 2
    List copy ya save kijiye

    Copy: list pe ungli daba ke rakhiye → "Select all" → "Copy".
    Save (PDF link bhi aayega): Chrome ⋮ menu → ⬇ Download. File phone mein save ho jaayegi.
    Har page (1, 2, 3…) alag-alag daal sakti hain, machine sab jodti jaayegi.

  3. 3
    Yahan daaliye

Abhi koi bid nahi daali

Goods ya services ka faisla bid ke naam se hota hai ("Custom Bid for Services", hiring, manpower, AMC jaise shabd services maane jaate hain). Bid lagane se pehle hamesha GeM pe asli PDF padhiye. Ye list sirf isi phone mein save hoti hai.
